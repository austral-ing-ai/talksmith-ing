## NOR-TDE-02 · Código ACV

§1. Cuando el motivo de consulta registrado en el triage es signos neurológicos focales de inicio súbito, la admisión activa el Código ACV dentro del plazo fijado en el parámetro P-TDE-2, contado desde el ingreso. No se espera la evaluación médica ni las imágenes para activarlo.

§2. Al activar el Código ACV se informa la hora de inicio de los síntomas. Si no se la conoce, por ejemplo porque el paciente se despertó con los síntomas, se informa la última hora en que se vio bien al paciente. Si la nota de triage no trae ese dato, se le pregunta al paciente o a su acompañante.

§3. El Código ACV no se activa cuando el motivo de consulta es otro.
