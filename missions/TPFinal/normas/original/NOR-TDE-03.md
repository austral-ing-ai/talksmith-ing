## NOR-TDE-03 · Sepsis

§1. Cuando el triage registra sospecha de sepsis, la admisión activa el Código Sepsis dentro del plazo que corresponde a la categoría que consignó enfermería, contado desde el ingreso: para la sepsis probable o con signos de shock rige el parámetro P-TDE-3, y para la sepsis posible sin signos de shock, el parámetro P-TDE-4.

§2. El Código Sepsis moviliza al equipo médico para la toma de hemocultivos y el inicio del antimicrobiano. La admisión no interviene en esas decisiones.

§3. El Código Sepsis no se activa si el triage no registra sospecha de sepsis.
